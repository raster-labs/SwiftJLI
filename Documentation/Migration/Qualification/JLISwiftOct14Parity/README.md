## Limitations and non-claims

- Finite source and functional parity audit, not a security certification.
- No new performance, heap-allocation or process-RSS qualification claim is made in this follow-up.
- Physical devices (including physical Watch) and non-iOS simulators were outside the owner-authorised validation scope for this task.
- Predecessor caller-workspace APIs (`JLICoreOutcome`, `JLIBaselineCallerStorage`, `JLILosslessCallerStorage`) and additional scan layouts (post-scan `DRI`/`DQT`, multiple sequential scans, undersampled luminance, subsampled XYB) remain explicit capability/architectural differences.
- No PR merge or stable release is authorised by this follow-up task.
