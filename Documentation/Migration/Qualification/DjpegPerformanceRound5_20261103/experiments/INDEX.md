# Round-five experiment archive

This is a durable record of completed investigations while optimisation continues. It is **not a final qualification report, a claim that SwiftJLI beats djpeg in every case, or a release approval**. “Integrated” below means the implementation was selected and incorporated into the working branch; the performance and platform limits remain as stated in each receipt.

The predecessor is `bbb0b1a9a602807643fc254fb4e0d54a162d5ae8`, with production code unchanged from round-four `0a8acd7`. The integrated source boundary is `425bfa4b996c39b6fde727af4bdd795b62cc4652`. Its release/comparator run was still live when the first archive was prepared; the completed intermediate receipt is now included as a separate append. Later completed checkpoints are appended with their own source boundaries; incomplete candidates and final release qualification remain excluded. Suite policy remains **0.10.0**, with a Swift 6.2 manifest minimum, Swift 6.4 primary toolchain and Apple OS 26 minimum. Exact commit identities and child-to-root mappings are in [SOURCE_PINS.json](SOURCE_PINS.json).

## Evidence integrity

[SOURCE_MANIFEST.json](SOURCE_MANIFEST.json) records the original absolute path, archived relative path, byte count and SHA-256 of every copied file. The 471 copied files are byte-for-byte originals; historical wording, intermediate failures and raw timing outliers have not been rewritten. Older receipts can describe a then-pending experiment that a later receipt resolved. Use the disposition table below to distinguish those states.

The archive contains text, JSON/JSONL, logs, patches and harness source. It excludes executable and object files, libraries, downloaded ZIPs, test bundles/dSYMs, image/ICC fixture payloads, credentials and signed-download URLs. Nineteen large profiler/CI dumps or duplicate disassemblies are omitted with their original hashes and reasons recorded. Compact crash/disassembly proof, hotspot summaries, command receipts and fixture provenance remain. Binary and fixture identities are also retained in the original experiment manifests; those payloads are not copied here.

Raw patches retain context-line spaces, and the initial paired-AC compiler log retains its whitespace. A whole-archive `git diff --check` reports these preserved bytes; authored Markdown/JSON and verifier code are checked separately. The source receipts are not normalised to silence the checker.

Run `python3 verify_archive.py` from this directory to verify all archived hashes and JSON syntax without accessing the original temporary paths. Harness scripts preserve their original commands and absolute paths; they require the pinned sources, dependencies and fixtures to be reconstructed before reuse. Verification does not run a benchmark.

## Interpretation and unexecuted gates

Timing results are provisional under unrelated host activity. A paired/reversed order and exact output check reduce specific biases but do not make a contended host a controlled machine. Raw samples, slow rounds, source/compiler/object identities, warmups and measured-sample counts remain available. The tiny batched harness includes release/deallocation; the ordinary individual-decode harness excludes output release. Those measurements must not be pooled.

The owned-output comparator uses full resolution and fixed quality gates: exact lossless samples, maximum difference 2 for 8-bit DCT and 4 for 12-bit DCT. RGB/progressive records with maximum difference 3 are excluded from the 8-bit gate. A runner status of `passed` means the harness completed with those exclusions preserved; it does not make excluded cases wins. The pinned Homebrew static libjpeg archive emitted macOS 27 target warnings when linked into the OS 26 diagnostic harness. It ran on macOS 27.0.1; this is not OS 26 qualification and does not change the product floor. No shim ASan/TSan or cross-platform qualification is claimed.

The CI archive preserves unsuccessful setup attempts: missing `Testing.framework`, missing fixture resources, and an unavailable Rosetta Swift test driver. LLDB's exit code 0 is a debugger exit after an inferior crash, **not a test pass**. The original Swift 6.3.3 binary was reproduced using the local Swift 6.4.2 runtime, so the reproduction identifies the failure site without claiming the same complete CI environment.

The first archive excluded then-live CI, compact-DC and grouped-memory work. Completed compact-DC and grouped-memory receipts were subsequently appended as separate source-pinned groups. The earlier completed CI 0d56/a491 logs are not copied into this archive. The new flag revision and later incomplete candidates remain excluded; completed checkpoint reports are linked below. Existing [integration checkpoints](integration-checkpoints) are historical logs for their named sources, not a merged count or validation of subsequent changes. Final library/CLI/oracle, ASan/TSan, supported-toolchain/platform and performance qualification remain separate from this archive.

The completed-evidence append adds only `bit-shifts/` and `integrated-425bfa4/`. The bit-shift lossless and DCT harness identities match the already-archived [lossless harness](parser-polling/native-matrix.swift) and [DCT harness](harnesses/swiftjli-round2-dct-benchmark.swift). Original source-file hashes are unchanged; `SOURCE_MANIFEST.json` records the append separately.

## Completed grouped and compact trials appended

[Grouped reconstruction](grouped-tiles/README.md) is based on `425bfa4`, candidate `b0266d8` (root integration `0b39c4a`). Its 35 focused tests in 8 suites passed. Twelve accelerated and six scalar fixtures in two paired rounds retained exact output. Large 12-bit DCT latency improved about 10%; the one-shot probe RSS median fell from 56,934,400 to 23,412,736 bytes. This is a Swift revision comparison, not a libjpeg memory win.

[Compact DC-only decoding](compact-dc/decision.json) is based on `425bfa4`, candidate `9e3b315` (root integration `f4a05be`). Its corrected gate passed 56 tests in 11 suites; 18 fixtures in two rounds retained exact output. The initial restart-order test incorrectly assumed the retained reader rejects swapped RST numbers; the original failure and corrected reference-behaviour test are preserved. Flat 512-square latency improved 27–33%, with a bounded 8 KiB payload replacing 512 KiB.

These are separate completed trials. The root merged plan additionally keeps compact scans at one lane and 1,024 blocks even for large images; the above trial counts do not validate that merge. Root sanitizers and cross-platform qualification remain separate. The earlier exclusion statement records the archive's initial scope; these two now-completed groups supersede their live exclusion only.

## Extended AC, narrow-buffer and profiling append

[Extended AC lookup](extended-ac/decision.json), `ec861325347806d9967237c3e8e92442d535dfd1` on `14f3501`, is **rejected**. Its 22 tests/6 suites passed; the DCT and lossless comparisons retained exact outputs. Modest/inconsistent DCT changes did not justify repeated flat/ramp lossless regressions. Four immediately paired repeats retained flat slowdowns of roughly 13–38% and ramp slowdowns of roughly 5–16%. [Raw targeted results](extended-ac/targeted-results.json), [ordinary lossless matrix](extended-ac/lossless.json), [DCT matrix](extended-ac/native-dct.json) and [pinned patch](extended-ac/trial-ec86132.patch) preserve the rejected result. The [zero-run opcode hashes](extended-ac/zerorun-codegen.json) match, while [other generated functions differ](extended-ac/changed-functions.json); the source-level cause was not established. Comparator, sanitizers and oracle were not run after this failed timing gate.

[Narrow coefficient pipeline](narrow-pipeline/decision.json), `3f18c9fc44d4c2bcb9cc978d566859658d2ce63a` on `14f3501`, is **rejected**. One Int16 coefficient slot plus two Float buffers lowers the explicit payload from 768 KiB to 640 KiB without losing representable coefficients. The 58 focused tests/11 suites and all 12 fixture pairs in two rounds passed. Independent source review found no concrete ownership, race, deadlock or resource-bound defect. Nevertheless DCT12-2048 latency increased 14.5%/15.3%, noise8-512 increased 10.7%/10.0%, and DCT12-512 increased 4.5%/7.2%. RSS was not measured; no memory-performance win is claimed from the structural payload alone. Full suite, lossless matrix and sanitizers were skipped after rejection. The [source/index](narrow-pipeline/index.json), [patch](narrow-pipeline/trial.patch) and [native raw results](narrow-pipeline/native.json) remain frozen; production was not changed.

[Pipeline profiling](pipeline-profile/findings.json) is **diagnostic only**, using the frozen `704ddae` object SHA-256 `9604e96a89586c07368942799ce1c29fa835fcdfc466c0b1e20074a76d6de9ed`, production-equivalent to `14f3501`. All four profiling outputs match the previously qualified full-output hashes. AC entropy accounts for 72.9% of producer samples in dense512, 75.3% in noise12-512 and 85.7% in dense2048. These are per-thread wall-clock stack-sample proportions, not CPU-cycle measurements or lookup miss rates. The reconstruction worker spends more than half its queued-thread samples waiting for entropy. Partial BLAS unwinds mean named IDCT frames alone undercount transform work. The [thread summaries](pipeline-profile/sample-summary.json), [AC breakdown](pipeline-profile/ac-breakdown.json), [compact disassembly](pipeline-profile/decodeAC-disassembly.txt), [harness and commands](pipeline-profile/manifest.json) preserve the diagnostic basis. The initial harness-only CocoaError member compile failure is retained; the corrected harness compiled and all sampling processes exited zero.

Four roughly 500 KiB raw stack dumps and four duplicate full assembly dumps were omitted in this append, with original paths, sizes, SHA-256 values and reasons retained in `SOURCE_MANIFEST.json`. Compact summaries, opcode hashes, the focused lossless-closure diff and the AC disassembly remain. Recomputing the sampling summaries requires those original raw dumps; archive verification checks the retained artefacts only. No binary, fixture, new accepted optimisation or benchmark threshold change was added.
