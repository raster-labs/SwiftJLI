DICOM boundary: owner explicitly chose to preserve JPEG shipping API and DICOM test support. No public DICOM product is requested.

1. All three DICOM support files match predecessor algorithms exactly after removing access modifiers and the Accelerate availability wrapper. See codex-inherited-support-comparison.json. This establishes migration parity, not correctness of every broad historical claim.
2. DICOMReader.decodeIntensities masks the lowest bitsStored bits and ignores highBit after parsing. Canonical highBit == bitsStored-1 works; shifted legacy samples do not. Independent ordinary-value harness dicom-normal-value-oracle.swift tested 56 small cases: 12 canonical cases pass and 44 shifted cases disagree; no process crash. Values include signed/unsigned extrema and unused-bit patterns, followed by exact modality rescale. Logs and command JSON retain this baseline result and the initial compiler-cache sandbox error/retry. Target DICOMReader hash at comparison: d5a6afc113277eb58b9cb5c979231b971b4a63ff00ca81140f71935bc261b435.
3. Current NEMA PS3.5 section8.1.1 requires HighBit=BitsStored-1 but notes the prior general-case rule allowed other positions (see PS3.5 2014c). Therefore any shift repair is legacy compatibility, not a claim current canonical DICOM samples were broken. https://dicom.nema.org/medical/dicom/current/output/chtml/part05/chapter_8.html (read 15Oct2026, rendered2026d).
4. Native DICOM frame count clamps to complete frames; it does not reject every incomplete multi-frame dataset. The existing test lyingFrameCountClamped explicitly preserves that behaviour. Do not claim universal truncation rejection.
5. Existing YBR_FULL_422 test uses full-resolution triplets, not native packed4:2:2. Current support has a3-bytes/pixel native layout. Label that limit and avoid claiming packed4:2:2. NEMA PS3.3 C.7.6.3: https://dicom.nema.org/medical/DICOM/current/output/chtml/part03/sect_C.7.6.3.html .
6. Existing encapsulatedMultiFrame test uses exactly1 fragment/frame and takes the shortcut before BOT grouping. Actual multi-fragment BOT grouping deserves a valid normal-data regression before claiming that branch executed.
7. Tests/Native/RegressionCorpusTests is a9-case deterministic synthetic corpus with frozen SHA256s. Clinical-style metadata is not new real-patient-data validation. Historical predecessor clinical claims stay historical.
8. abc040f's RGBA CGImage and CoreGraphics storage lifetime fixes live in JLILab/Sources/Render.swift and ImageLoading.swift. These app paths were not shipped by SwiftJLI. Public SwiftJLI padded-row decode and explicit alpha-discard policy have separate coverage (JPEGMigrationTests, JPEGDecodeParityTests, ColourInputTests).
9. Public standalone JPEG rejects signed descriptors (layout integer policy) and ambiguous lossless colour IDs. Inherited native signed bit-pattern tests are not proof of public signed JPEG metadata support.
